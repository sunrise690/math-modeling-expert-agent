# 几何、轨迹与连续事件建模

适用于轨迹相交、可见性/遮挡、碰撞、覆盖窗口、进入/离开区域和移动设施服务窗口等题目。

## 1. 先固定语义，再写距离公式

把判据写成布尔命题，并区分三类对象：无限直线、有限线段、具有面积或体积的真实目标。题意存在合理歧义时，不可静默选择：确定一个与填表和后续优化一致的主评分口径，并对同一决策变量执行更保守的二次审计。正文同时报告两者，不能把不同口径下的数值混成一个“最优值”。

## 2. 运动学与几何层分离

先分别定义平台、投放物、云团/服务区和目标的状态函数，再定义几何判据。所有坐标、时间原点、角度方向和单位必须显式记录。落体、下沉或衰减采用分段状态时，事件前后函数要分开，不能把尚未发生的状态外推到全时间域。

## 3. 连续事件求解

粗时间网格只用于发现候选区间。正式边界应对事件函数 `h(t)=0` 使用括区间求根（如 Brent），再用区间中点确认布尔状态。对多个事件区间先排序合并，再计算并集测度；不得直接相加导致重叠重复计时。

至少记录：

- 根的左右端点、事件函数残差和求根容差；
- 网格加密前后的区间长度差；
- 退化边界（零延时、切触、端点相交、空区间）；
- 与解析特例、独立实现或高精度采样的一致性。

## 4. 真实目标的保守审计

对圆柱、球、矩形或多面体等扩展目标，中心点视线通常只是代理判据。保守审计应覆盖可能的最不利边界点，并进行角向/空间节点加密；离散节点仅用于候选定位，最终仍应连续精化边界。若完整覆盖条件比中心代理显著降低目标值，应把差异列为模型口径敏感性，而不是算法误差。

## 5. 优化结论边界

几何区间并集往往非光滑。可用全局候选生成、分层搜索、波束/指派与局部精化组合，但必须固定随机种子并报告可行性、约束违反量、多初值差异和二次复算结果。没有可验证全局界、穷举证明或凸性充分条件时，只能称“高质量可行解”或“当前搜索所得最好方案”，不得称全局最优。
