# 证据与验证契约

## 证据等级

1. 题面证据：题面、附件字段、官方模板和规则。
2. 来源证据：已读取的讲义、论文、官方文档原文。
3. 计算证据：成功运行的代码输出、结果表、求解器日志。
4. 验证证据：独立复算、收敛、残差、约束、灵敏度和鲁棒性结果。

结论必须绑定到足够等级的证据。模型选择可由来源证据支持；具体最优值必须由计算证据和验证证据共同支持。

## 主张—证据表

为每个关键主张记录：子问题、主张文本、数值与单位、生成脚本、输入文件、输出表/图、验证方法、状态。状态只允许 `verified`、`provisional`、`failed`。

## 按任务验证

- 优化：可行率、最大约束违反、收敛、多初值或独立算法。
- 机理：量纲、边界、守恒或几何一致性、步长收敛、极限情形。
- 统计：假设诊断、区间和效应量，不只给 p 值。
- 预测：防泄漏划分、基线、外推或交叉验证、误差分布。
- 仿真：预热、重复、置信区间、随机种子和停止准则。
- 评价：权重扰动、排名稳定性和替代方法对照。

任何 `failed` 主张不得进入摘要或最终推荐；`provisional` 必须在正文中明确限制。
