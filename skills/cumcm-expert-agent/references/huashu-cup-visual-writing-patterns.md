## 1. 审读范围与方法

本参考对第四至第六届全部 18 篇论文执行：全文题注扫描、正文候选页低分辨率色相统计、每篇至少 1 个代表性图表页人工回看；高彩色论文额外回看至 3 页。自动扫描共识别 243 个图题、123 个表题。

像素统计仅用于定位：地图底图、照片、校徽、抗锯齿和扫描底色都会影响颜色占比。以下审美与语义判断来自实际页面回看，不由色相计数直接推断。

最值得迁移的是“颜色为什么存在”，不是历史论文的 Office/MATLAB 默认外观。保留主张—图—解释闭环，重绘过小字号、彩虹色、饼图、无色条三维图、装饰性粉彩流程图和双 Y 轴。

## 3. 配色决策表

先判断变量语义，再选颜色。不能先选“好看色板”再套数据。

| 数据/主张 | 允许的颜色结构 | 强制条件 | 禁止 |
|---|---|---|---|
| 单一数据 + 阈值/基线 | 主蓝 + 朱红强调 | 数据与阈值同时用线型/标记区分 | 两条同线型只靠红绿 |
| 非负连续量 | `viridis` 或 `cividis` 顺序色图 | 色条、单位、范围、缺失值颜色 | `jet/rainbow`、无色条 |
| 有正负偏差/相关 | 蓝—白—橙发散色图 | 中心固定为 0；相关矩阵固定 `[-1,1]` | 单向蓝色、非对称色域制造差异 |
| 类别比较 | Okabe-Ito 子集，通常 2-5 色 | 同类跨图固定颜色；再用标记/线型 | 每根柱随机换色、低对比粉彩 |
| 多算法/多方案 | 主色深浅 + 线型/标记 | 基线永远固定中性深灰或主蓝 | 只靠一排彩色图例 |
| 空间地图 | 去饱和底图 + 路线蓝 + 节点橙 | 直接标注、底图来源、比例尺/方向 | 把底图颜色当数据图例 |
| 光谱/真实颜色 | 波长或通道可使用物理语义色 | 同时保留线型、通道名和数值表 | 用真实光谱色编码无关类别 |
| 流程/机理结构 | 中性灰 + 主色 + 强调色 | 颜色表示层级或状态，并在图例说明 | 粉/黄/青/绿分栏装饰 |
| 不确定性 | 主线 + 同色低透明带 | 图注写区间类型、样本量/重复次数 | 多条浅色随机轨迹充当鲁棒性 |

## 4. 可直接复用的论文色板

### 4.1 默认定量论文色板

| 角色 | Hex | 用途 |
|---|---|---|
| 主色蓝 | `#3B6FB6` | 主要数据、主模型、路线 |
| 次色青绿 | `#2A9D8F` | 第二方案、通过状态、辅助变量 |
| 强调朱红 | `#D55E00` | 阈值、失败、关键事件、禁止区 |
| 强调橙 | `#E69F00` | 代表方案、节点、警示但非失败 |
| 中性深灰 | `#374151` | 基线、正文图线、坐标轴 |
| 中性灰 | `#6B7280` | 次要方案、置信边界 |
| 浅网格 | `#D9DEE7` | 轻量网格和分隔线 |
| 背景 | `#FFFFFF` | 论文白底 |

默认一张定量图只用中性灰 + 1 个主色 + 1 个强调色。需要更多实体时，从 Okabe-Ito 子集依次取 `#0072B2`、`#E69F00`、`#009E73`、`#D55E00`、`#CC79A7`；超过 5 类优先改图型、分面或直接标注。

### 4.2 发散与连续色图

- 非负连续量：`viridis`；对灰度/色觉缺陷要求更高时用 `cividis`。
- 相关、残差和相对变化：蓝—白—橙 `#2166AC → #F7F7F7 → #B35806`，中心固定 0。
- 概率、p 值或风险若越小越关键，不得只反转色条而不写方向；题注必须明确“深色代表更大还是更显著”。
- 缺失值固定浅灰 `#D1D5DB`，不得与数值 0 共色。

### 4.3 场景固定语义

- 可行/通过：青绿；不可行/违反：朱红；候选/待验证：橙；基线：深灰。
- 日间/夜间：主蓝/橙；跨整篇固定，不得在不同图中互换。
- 训练/验证/未来：深灰/主蓝/橙，并用线型和背景分区冗余表达。
- 真实 LED 通道：可按通道物理波段设色，但“冷白/暖白”必须另加线型和直接标签，保证灰度可辨。

## 5. 按图型的强制规则

### 5.1 热图与相关矩阵

- 先判断值域是非负还是有正负。
- 相关矩阵固定对称色域 `[-1,1]`，0 为中性白；显著性用 `*`、描边或透明度，不另加彩虹层。
- 单元数字精度不超过数据精度；矩阵过大时聚类/排序并分组，不缩到不可读。

### 5.2 收敛与优化图

- 主图显示目标值相对函数评估次数/时间，不只对迭代编号。
- 随机算法显示多种子中位数与四分位带；单次最好曲线只作附加。
- 同图加入简单基线和可行边界；约束违反量单独成图或第二面板，禁用双 Y 轴。

### 5.3 三维曲面与点云

- 只有二维投影会丢失关键关系时才使用 3D。
- 必须有色条、单位、视角、等比例/物理比例和二维截面。
- 密集工作空间点云优先改凸包/包络、二维投影或可达概率/距离场。

### 5.4 地图与路线

- 底图去饱和，不能与路线抢占视觉层级。
- 路线使用主蓝，节点/事件使用橙或朱红；起点、终点和候选点用形状区分。
- 题注写交通方式、时间/距离口径、地图来源；路线旁给关键时长或预算，不只展示地名。

### 5.5 柱图、饼图与堆叠图

- 无分布信息的均值柱图不作为默认；优先点图、箱线/小提琴 + 原始点或估计区间。
- 饼图原则上禁用；类别占比改排序条形或 100% 堆叠条。
- 堆叠面积只在“总量 + 组成”同时重要时使用。类别超过 5 个先聚合，不能给每个用户一色。

### 5.6 流程图

- 流程颜色表示模型层次、数据状态或风险，不表示“第几问”。
- 默认中性灰框；主路线用浅蓝，验证/回滚用浅橙或朱红描边。
- 删除阴影、渐变、胶囊、装饰性箭头和过长框内文字；最终页面字号不小于 7 pt。

## 6. 图文与题注写法

题注是微型论证，至少回答：

1. 图中对象、条件和单位；
2. 颜色、线型、标记和阴影分别表示什么；
3. 样本量、重复次数或区间类型；
4. 基线、阈值和关键事件在哪里；
5. 读者应看到的定量结论与限制。

正文解释按“三步法”：先报关键数值，再解释模型内部原因，最后说明决策/物理意义和适用边界。禁止“由图可知效果很好”。

表格与图互补：精确值、约束余量和方案字段用三线表；趋势、分布、空间关系和不确定性用图。不得用颜色替代精确结果表。

## 7. 成图回看门禁

每张正式图必须全部通过：

1. `figure_intent` 说明唯一主张和新增证据；没有新增证据则删图。
2. 变量跨全文同色、同线型、同标记；语义色映射登记在颜色联系表。
3. 颜色之外有线型、标记、标签或位置冗余；灰度版可辨。
4. 色图与值域语义匹配；连续色条有单位和范围，发散色图中心正确。
5. 无彩虹、饼图墙、装饰性 3D、无语义双 Y 轴、随机粉彩柱、拥挤堆叠面积图。
6. 150 DPI 预览无缺字、重叠、裁切；最终 PDF 实际尺寸中文字不小于 7 pt。
7. 地图、图片和外部标准图注明来源；图内数字来自结果文件，不手工录入。
8. 最终 PDF 跨渲染器检查字体嵌入；出现缺字、空表或标题不可恢复时直接失败。

自动颜色像素统计只能帮助选页，不能替代上述人工语义审查。
