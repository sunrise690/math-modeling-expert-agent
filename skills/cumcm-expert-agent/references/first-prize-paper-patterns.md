## 3. 跨论文可复用的高水平模式

### 3.1 先建立“现实语义—数学对象—计算对象”的桥

高质量路线不会从算法名开始，而是先回答：系统里什么在变化、什么受守恒或几何关系约束、观测量如何生成、决策量如何改变结果。

- A147 从微元能量平衡得到一维热传导方程，再把炉区温度、PCB 温度、传送速度和工艺约束连接起来。来源：A147，PDF p.5–15，“模型的建立及求解”。
- A001 先分解波浪能装置受力和转矩，将二阶动力学方程化为状态方程，再用 RK4 计算稳态响应和平均功率。来源：A001，PDF p.5–12，问题一、问题二。
- A242 由等距螺线弧长和相邻把手刚性距离得到位置、速度递推，而不是直接对坐标做经验拟合。来源：A242，PDF p.5–7，“盘入运动模型的建立”。

Agent 规则：输出任何模型前，必须生成一张“语义映射表”，至少包含实体、状态、控制/决策、观测、参数、约束、输出、单位和时间/空间尺度。没有完成这张表，不得直接推荐算法。

### 3.2 多问赛题应形成一条可复用的模型链

优秀论文常把前一问的模型变成后一问的计算内核：机理模型成为优化器的评价函数，几何递推成为碰撞检测与路径优化的状态生成器，预测结果成为决策模型的输入。

- A147 的热传导模型贯穿参数辨识、速度优化、工艺曲线优化。来源：A147，PDF p.12–25。
- A001 的动力学模型被复用于阻尼优化与输出功率优化。来源：A001，PDF p.10–20。
- A242 的盘入递推被复用于碰撞时刻、最小螺距、调头运动和最大速度。来源：A242，PDF p.9–29。
- C050 呈现“销量/价格关系与需求预测—补货定价决策”的完整意图，即使其具体耦合实现存在缺陷。来源：C050，PDF p.12–20，问题二、问题三。

Agent 规则：为每一问标记“新增模块、复用模块、输出到下一问的接口”。若下一问另起炉灶，必须解释为什么前一问结果不能复用。

### 3.3 用领域结构降维，再调用优化器

高价值的“聪明”通常发生在调用算法之前。

- A175 用邻接矩阵/邻域关系缩小遮挡与阴影检查范围，并用蜂窝式布局减少设计自由度。来源：A175，PDF p.12–17。
- A127 通过同心区域布局、塔位先验和分区参数化降低镜场设计维数。来源：A127，PDF p.15–24。
- B334 把逐秒过程改写为事件时刻上的状态转移与队列更新。来源：B334，PDF p.5–15。
- A242 先尝试证明首次碰撞只需在内外相邻圈检查，再做动态搜索。该证明并不充分，但“先做广相筛选、再做精确窄相检测”的思想可迁移。来源：A242，PDF p.9–13。

Agent 规则：任何高维或昂贵问题，先提出至少一种结构降维方案，并同时给出“不会漏解”的证明、保守上界，或独立全量抽查。只有加速、没有漏检审计的降维不得视为可靠。

### 3.4 模型必须显式写出变量、目标、约束与可交付量

- A127、A175、A242 均把设计变量、目标函数、几何/功率/安全约束单列出来。来源：A127，PDF p.17–19；A175，PDF p.15–17；A242，PDF p.14–15、p.26–28。
- B334 给出状态、工序、服务时间和加工周期，再以调度规则生成方案。来源：B334，PDF p.5–15。
- E176 把监测时点选择写成 0-1 规划。来源：E176，PDF p.17–19。

Agent 规则：每个优化问题都必须生成“模型卡”：决策变量及域、目标方向和单位、逐条约束、容差、基线可行解、求解器、终止条件、输出表字段。变量只在代码中出现而正文没有定义，视为交付失败。

### 3.5 分层求解优于一次性黑箱搜索

- A147 使用粗搜索、局部细化与约束检查获得工艺方案。来源：A147，PDF p.17–25。
- A242 使用大步长定位事件区间，再以二分/三分搜索精化；PSO 参数也在正文披露。来源：A242，PDF p.12、p.15–17、p.27–28。
- A127、A175 都先用结构化布局缩小参数空间，再做搜索。来源：A127，PDF p.15–24；A175，PDF p.15–18。

Agent 规则：默认采用“可行域构造—粗筛—候选精化—独立复算”的四层求解。若用随机启发式算法，必须保存种子、重复运行、报告分布，并由确定性可行性检查器重算最终方案。

### 3.6 摘要应是逐问结论表，而不是方法名清单

这 9 篇论文的摘要普遍按问题逐项叙述，并给出关键数值或定性结论。A147、A001、A242 尤其清楚地把“模型—算法—结果”绑定。来源：各文件 PDF p.1。

Agent 规则：摘要中的每个数字必须链接到正文表/图、生成脚本和验证状态；正文没有验证的结果只能写“当前计算所得”或“近似可行解”，不能写“最优”“准确”“可靠”。

### 3.7 验证必须与主张类型匹配

样本中可取的验证方式包括：

- 机理拟合与实测曲线对照：A147，PDF p.14–17。
- 周期/物理特征核对：A001，PDF p.21。
- 理论上界与调度结果比较：B334，PDF p.15–18。
- 几何状态图、阈值曲线、另一种速度计算方法交叉验证：A242，PDF p.13、p.16–17、p.26、p.28–29。
- 回归置信区间与残差图：E176，PDF p.6–7。

Agent 规则：不能用“图看起来合理”替代数值验证，也不能用训练拟合替代外推验证。验证必须至少包含一项独立于主求解器的证据。

### 3.8 代码和结果表应与正文形成可复现闭环

所有样本都在主文末尾给出程序或附录位置；A147、A001、A242 明确把完整结果表指向外部表格/附录。来源：A147，PDF p.27 及后续；A001，PDF p.23 及后续；A242，PDF p.7、p.12、p.23–25 及后续。

Agent 规则：最终交付至少包含环境清单、入口脚本、输入哈希、随机种子、结果表、绘图脚本、求解日志、验证报告和论文引用映射。只给论文、不给可复跑产物，不能标记为完成。

## 4. 逐篇解剖：应吸收什么，不能照抄什么

### 4.1 A147：一维热传导与炉温曲线

可迁移做法：

- 从微元能量平衡推导热传导方程，明确炉内环境温度和 PCB 温度的联系；随后把 PDE 数值解变成参数拟合和优化的评价器。来源：A147，PDF p.5–15。
- 用拟合曲线和决定系数检查模型与测温数据的一致性，报告 R²=0.9813；再对部分参数做敏感性分析。来源：A147，PDF p.14–17。
- 将工艺约束、速度范围、温区时间和面积等指标显式写入优化问题，并采用由粗到细的搜索。来源：A147，PDF p.17–25。

需警惕：

- 有限差分求解没有提供空间步长、时间步长的系统收敛表，也没有明确稳定性条件。来源：A147，PDF p.12–15。
- R² 来自同一组数据的拟合，未见留出段、残差自相关、异方差或参数置信区间。来源：A147，PDF p.14–16。
- 敏感性分析没有充分披露扰动规则；其中个别灵敏度并不小，却仍笼统宣称模型稳定。来源：A147，PDF p.16–17。
- 问题四采用等权 1:1 和样本最大值归一化，权重与标度缺乏依据。来源：A147，PDF p.22–24。
- 文中称“A*”的过程更接近启发式局部搜索，且因比赛时间提前停止，不能据此宣称全局最优。来源：A147，PDF p.21–25。

Agent 应吸收：守恒推导、边界条件、参数辨识、工艺约束的链条。Agent 必须补上网格收敛、留出验证、参数不确定性、权重扰动和最优性边界。

### 4.2 A001：波浪能装置动力学与功率优化

可迁移做法：

- 根据受力和转矩建立动力学方程，化为一阶状态系统，用 RK4 计算响应。来源：A001，PDF p.5–9。
- 在稳态时间窗上计算平均输出功率，并把阻尼参数作为决策变量。来源：A001，PDF p.10–12、p.18–20。
- 用响应周期与强迫周期的一致性、参数微扰进行基本物理验证；模型评价也承认忽略耦合的局限。来源：A001，PDF p.21–22。

需警惕：

- 虽使用很小的时间步长 0.0001，未报告步长减半后的结果差、守恒量或参考解，不能仅以步长小证明精度高。来源：A001，PDF p.6–9。
- “响应周期等于外力周期”只是必要的合理性检查，不足以证明幅值、相位、功率积分都正确。来源：A001，PDF p.21。
- 鲁棒性仅对单一惯量参数做约 ±1% 扰动，未覆盖关键水动力系数和耦合项。来源：A001，PDF p.21–22。
- 遗传算法未完整报告随机种子、多次运行分布、收敛曲线、确定性基线或全局界。来源：A001，PDF p.18–20。

Agent 应吸收：状态空间、稳态截取、周期平均功率。Agent 必须补上步长收敛、暂态长度敏感性、随机优化复跑、相位/幅值残差和关键参数联合不确定性。

### 4.3 A127：定日镜场输出功率优化

可迁移做法：

- 从坐标系、反射方向、遮挡/阴影、余弦效率和截断效率构造完整光学计算链。来源：A127，PDF p.4–14。
- 明确披露离散规则，例如每面镜的采样点和射线数量，使计算复杂度可追踪。来源：A127，PDF p.13–14。
- 先确定塔位与同心分区布局，再优化区域参数，显著降低镜场直接逐镜优化的维数。来源：A127，PDF p.15–24。
- 提供方案对照和灵敏度分析。来源：A127，PDF p.20–26。

需警惕：

- 射线/镜面离散没有网格加密收敛，也未用独立几何实现复核。来源：A127，PDF p.13–14。
- 针对塔位或偏移量的二分/单调搜索依赖单调性，但正文没有充分证明。来源：A127，PDF p.19–24。
- 最严重的跨问一致性错误：问题二固定镜宽高的方案给出单位面积年均输出约 0.587120 kW/m²；问题三放开镜面尺寸和安装高度后给出约 0.530652 kW/m²。若问题三可行域包含问题二方案，最大化问题的最优值不可能降低。来源：A127，PDF p.20–21、p.24–25。
- 个别单位书写在 kW 与 MW 间不一致。来源：A127，PDF p.24–25。

Agent 应吸收：物理光学分解、区域化设计、方案对照。Agent 必须自动执行“嵌套可行域支配检查”，并把上一问的方案作为下一问求解器的保底初始可行解。

### 4.4 A175：定日镜场的另一条优化路线

可迁移做法：

- 用邻接矩阵/近邻检查减少逐镜两两遮挡计算。来源：A175，PDF p.12–13。
- 对离散步长和安装高度做敏感性测试，表明作者意识到数值分辨率影响。来源：A175，PDF p.14。
- 用蜂窝/规则布局缩减变量，以分阶段蒙特卡洛搜索快速找到候选区域。来源：A175，PDF p.15–18。
- 主动承认搜索可能是局部解。来源：A175，PDF p.2、p.17–18。

需警惕：

- 步长从 1.5 缩小到 0.25 时，单位面积输出从约 0.3791 增至约 0.4029，变化约 6.3%，却把较粗步长称为“稳定”，证据不足。来源：A175，PDF p.14。
- 蒙特卡洛阶段使用 10%×10、30%×5 等抽样，但未给种子、置信区间、样本量收敛或多次运行分布。来源：A175，PDF p.17–18。
- 在得到结果后才指出问题可能应做多目标优化，说明目标定义与求解路线没有在前期闭环。来源：A175，PDF p.18。
- 同样出现跨问支配错误：问题二约 0.572538 kW/m²，变量放宽后的问题三约 0.506192 kW/m²。来源：A175，PDF p.18–21。
- 参考文献包含百科网页，核心模型的一手学术依据偏弱。来源：A175，PDF p.21。

Agent 应吸收：近邻加速、规则布局、坦诚标注局部解。Agent 必须把“分辨率收敛”和“嵌套可行域不降性”设为硬门槛，随机采样必须有误差条和重复性报告。

### 4.5 B334：RGV 动态调度与随机故障

可迁移做法：

- 把加工系统改写为事件驱动的多队列/状态转移过程，避免逐秒模拟。来源：B334，PDF p.5–12。
- 用加工节拍、理论产能和平衡关系构造上界，再将调度产出与上界比较。来源：B334，PDF p.6–7、p.15–18。
- 调度规则由领域原则引导，并用时间线可视化解释方案。来源：B334，PDF p.12–17。
- 评价部分承认启发式算法只能得到近似方案。来源：B334，PDF p.18–19。

需警惕：

- 两道工序串联系统的产能应受较小产能约束，正文文字写“较低者决定”，公式却使用 max，公式与语义矛盾。来源：B334，PDF p.7。
- 定义偏差率 λ=|A−U|/U，但表中 0.9948 一类数值实际更像 A/U；若 A/U=0.9948，真正相对偏差应为 0.0052。来源：B334，PDF p.16。
- 摘要或结果把启发式输出称为“最大”，但没有穷举、精确规划、最优性间隙或可证明界。来源：B334，PDF p.1、p.15–18。
- 随机故障部分只展示一次故障实现及其产出，未报告重复仿真、置信区间、随机种子和分布。来源：B334，PDF p.15–18。
- 接近理论上界不等于最优，尤其当上界本身较松。来源：B334，PDF p.15–18。

Agent 应吸收：事件驱动状态机、瓶颈上界、时间线解释。Agent 必须增加状态不变量、公式—文字一致性检查、小规模精确求解对照，以及随机情形的多次复现实验。

### 4.6 C050：蔬菜定价与补货决策

可迁移做法：

- 先做品类、销量、价格和损耗的探索性分析，再尝试形成“预测—优化”决策链。来源：C050，PDF p.5–18。
- 给出描述统计、相关分析、聚类、回归、时间序列预测和结果表，覆盖面完整。来源：C050，PDF p.5–25。
- 注意到天气、节假日、替代关系等外部因素可能影响经营决策。来源：C050，PDF p.20–25。

需警惕：

- Spearman 检验把 H0 写成“相关系数不为 0”、H1 写成“等于 0”，与标准显著性检验相反；Pearson 部分也出现假设方向和结论逻辑不一致。来源：C050，PDF p.9–10、p.13。
- K-means 同时使用总销量、最大值、均值等量纲尺度差异大的特征，但未说明标准化；k=4 也缺乏轮廓系数、稳定性或替代聚类验证。来源：C050，PDF p.10–12。
- 日数据预测依赖软件“专家建模器”，未给时间留出、基线模型、预测误差或预测区间；同时出现把周期 m=4 解释为季度的尺度混乱。来源：C050，PDF p.14–17。
- 决策模型把需求 S 当作与价格独立的固定值，尽管前文已讨论价格—销量关系。这样利润常会把价格推到上界，复杂启发式搜索没有必要。来源：C050，PDF p.13–18。
- 结果表出现违反模型自身 R≥S 约束的情况：例如 2023-07-02 花菜类预测量约 34.29，而补货量约 20.122；另有预测量约 68.99、补货量约 65.201 的条目。来源：C050，PDF p.15、p.17–18。
- 问题三称线性规划，却又用模拟退火，且利润结构与需求量的关系没有闭环。来源：C050，PDF p.18–20。
- 评价中宣称预测准确、获得全局最优，但主文没有对应的外推误差和最优性证据。来源：C050，PDF p.26。

Agent 应吸收：从数据到决策的整体框架。Agent 必须重建为“价格影响需求—预测不确定性—补货/定价联合优化”，并强制执行时间切分、泄漏检测、约束逐行回算与简单基线比较。

### 4.7 D001：空气质量数据对齐与校准

可迁移做法：

- 在建模前检查记录时间的不连续点，并区分 EDA 中可容忍的缺失与差异分析中必须处理的对齐问题。来源：D001，PDF p.4、p.8–9。
- 以国控点小时为基准，把高频自建点数据按时间窗聚合，实现 4137 个时点的可比较样本。来源：D001，PDF p.8–9。
- 同时用关联度排序和多元线性回归分析影响因素，并报告 F、P、R² 与系数。来源：D001，PDF p.9–13。
- 给出校准前后曲线和残差总量对比。来源：D001，PDF p.13–15。

需警惕：

- 关键假设认为同一时间国控点与自建点的真实环境完全相同，对空间差异过强。来源：D001，PDF p.3，“基本假设”。
- 多个污染物和气象变量高度相关，却未见 VIF、条件数、残差诊断、稳健标准误或变量筛选。来源：D001，PDF p.7、p.10–13。
- 所谓校准主要是用全部国控点序列做分段线性插值，生成高频参考序列；它没有真正学习“自建点读数到国控真值”的映射，也无法证明在最后一个国控点之后可实时校准。来源：D001，PDF p.13–14。
- 插值函数通过已知国控节点，随后仍用同一批国控数据评价“残差降至 2.9%”，属于训练内/插值内评价，不能替代按时间留出的外推校验。来源：D001，PDF p.14–15。
- 评价提出算法易移植，但没有在线漂移、概念漂移、缺测和未来时段测试。来源：D001，PDF p.15–16。

Agent 应吸收：时间对齐、数据质量检查、校准前后对照。Agent 必须把插值、校准、预测三种任务区分开，并要求滚动时间验证、漂移监测和真正使用自建传感器读数的校准函数。

### 4.8 E176：水沙通量分析、预测与监测方案

可迁移做法：

- 从季节性、周期性、趋势和突变多个角度分析水文序列。来源：E176，PDF p.9–14。
- 双对数回归报告系数置信区间、R²、F 检验和残差图，比只报 p 值更完整。来源：E176，PDF p.6–7。
- 预测部分至少尝试用 2018–2020 年拟合、2021 年预测，存在时间外推意识。来源：E176，PDF p.15–17。
- 将采样时点选择转化为 0-1 规划，给出目标、约束和方案表。来源：E176，PDF p.17–19。

需警惕：

- 缺失值用邻近/均值替代、离群点直接剔除，但没有规则、数量、机制分析和敏感性。来源：E176，PDF p.3–4。
- 数据已按月整理，周期公式却在“365 天”和分母 12 之间切换，时间尺度叙述不一致。来源：E176，PDF p.9–10。
- M-K 对沙通量给出 t=27，Fisher 对沙通量给出 t=30，却仍称两者一致；小波又给出多组突变点。来源：E176，PDF p.11–14。
- R/S 只给趋势持续/反转判断，不能直接产生未来数值；把两个历史阶段都算 Hurst 指数并称为“检验/预测”不足以构成预测验证。来源：E176，PDF p.14–15。
- 用 36 个按月样本拟合 10 阶傅里叶级数，参数很多，存在过拟合和混叠风险。沙通量预测误差 24.6572，却笼统称“较小”，且误差公式/量纲解释不足。来源：E176，PDF p.15–17。
- 对预测序列再次做小波并以此证明未来波动，结论很大程度由傅里叶模型预设周期产生，不是独立证据。来源：E176，PDF p.17。
- 监测“信息量”定义为相邻差 x(t+1)−x(t)，却又假定其非负，公式缺少绝对值；方案只用水通量并据此代表水、沙两类目标。来源：E176，PDF p.17–19。
- 调水调沙效果仅做前后比较，没有反事实或混杂控制；GM(1,1) 只基于 4 个高程增量并做 10 年爆炸式外推，没有级比检验、后验差检验、留出验证或区间。来源：E176，PDF p.19–21。

Agent 应吸收：多视角时序诊断、时间留出意识、监测方案整数化。Agent 必须抑制“方法堆砌”，先定义互补证据，再做变化点一致性表、时间尺度审计、预测基线与区间、监测信息量语义检查和反事实边界说明。

### 4.9 A242：板凳龙几何运动、碰撞与路径优化

可迁移做法：

- 由螺线弧长微分方程求龙头位置，再由刚性距离递推所有把手位置和速度，数学对象与实体结构高度一致。来源：A242，PDF p.5–9。
- 用粗步长发现首次碰撞区间，再用二分搜索连续精化。来源：A242，PDF p.12–13。
- 把前一问的运动模型作为碰撞、螺距和速度优化的计算内核。来源：A242，PDF p.9–29。
- PSO 披露粒子数、迭代数和权重；三分搜索披露区间与 1e-8 容差。来源：A242，PDF p.15–17、p.27–28。
- 用几何动画/状态图、阈值曲线和数值微分对解析速度进行交叉验证。来源：A242，PDF p.13、p.16–17、p.26、p.28–29。

需警惕：

- 碰撞判定使用板凳顶点到另一板凳“前后把手所在无限直线”的距离，而实体是有限长度矩形。若垂足落在线段之外，点到直线距离会产生假碰撞；只检查部分顶点也可能漏掉端点—边、边—边或另一方向的顶点碰撞。来源：A242，PDF p.10–11。
- “首次碰撞必在最内圈和外侧相邻一圈”的证明主要依赖角速度直觉，没有穷尽所有板凳对；随后只在被裁剪范围内作图验证，存在循环验证。来源：A242，PDF p.9–13。
- 同一几何量在问题一写作龙头/龙身孔距 2.86m、1.65m，问题四递推却写成 2.96m、1.75m，和题面尺寸不一致。来源：A242，PDF p.6、p.21。
- PSO 未披露随机种子、重复运行统计或确定性全局下界；“多次实验稳定”没有数据表。来源：A242，PDF p.16–17。
- 问题五把全体把手索引缩为 n∈{0,1,223}，并把时间缩到两个窗口，主要依据观察而非严格上界，可能漏掉中间把手或其他时刻的峰值。来源：A242，PDF p.26–29。
- 对 max_n v_n(t) 的包络使用三分搜索要求目标在区间内单峰；图像支持局部单峰，但不能证明全时域全局最优。来源：A242，PDF p.27–29。

Agent 应吸收：解析几何递推、连续事件括区间求根、跨问复用和多种验证。Agent 必须升级为“广相筛选 + 有限矩形/线段精确窄相 + 全量抽查”，并对连续时间给出事件残差、时间容差和索引覆盖证明。

## 6. CUMCM 专家 Agent 的专用工作流

### 6.1 阶段 0：题面与资料取证

1. 记录题面、附件、补充材料的文件名、哈希和版本。
2. 对 PDF 先核验首页、代码、标题、年份和页数；奖项、作者、来源只按可见证据陈述。
3. 对附件输出字段字典、单位、时间范围、缺失、重复、异常编码和样例行。
4. 把资料中的直接事实、论文方法、Agent 推断和实际计算结果分成四类，不混写。

通过条件：生成“来源清单”和“证据等级表”；任何身份或数据口径不确定项都有明确标签。

### 6.2 阶段 1：逐问交付矩阵

每问至少记录：题目动词、输入、输出、精度、单位、必须填的表/图、与其他问的依赖、验收指标。

通过条件：题面中的每个动词和附件交付字段都映射到一个产物；不能只给思路而漏填结果表。

### 6.3 阶段 2：问题本质与路线竞选

至少提出两条可行路线，并对以下维度打分：机理可信度、数据适配、可解释性、计算代价、验证难度、比赛时间风险。路线选择必须说明淘汰理由，禁止为了显得复杂而堆模型。

通过条件：主路线、保底路线和独立验证路线三者角色明确。

### 6.4 阶段 3：模型卡与量纲审计

模型卡固定字段：

- 实体、状态、决策、参数、随机量。
- 坐标系、时间原点、正方向、采样频率。
- 目标函数、单位和优化方向。
- 每条约束、容差和物理来源。
- 初边值条件、守恒关系或状态不变量。
- 可识别性、适用范围与近似条件。

通过条件：每个加减项同量纲；无量纲化与还原可逆；数量级与极限情形合理。

### 6.5 阶段 4：先做最小可验证基线

在复杂算法前构造一个能跑通的小模型：解析特例、朴素调度、线性/季节基线、规则布局或小规模穷举。基线既是保底结果，也是后续算法必须超过的下界/上界。

通过条件：复杂模型没有比基线更差；若更差，先排查实现或口径，不得直接写论文。

### 6.6 阶段 5：主求解与工具编排

- PDE/ODE：优先使用可控制步长和容差的数值库；保留状态、事件、步长和失败日志。
- 优化：连续问题用 SciPy/专用优化器，多目标用 pymoo，线性/整数问题用可报告状态与最优界的求解器。
- 调度/仿真：事件驱动状态机；随机故障用多重复实验。
- 统计/预测：statsmodels/scikit-learn 等必须配时间切分、诊断和基线。
- 几何：广相筛选后，用有限线段、矩形/多边形或真实三维实体做窄相检测。

通过条件：求解器状态成功；失败重试不被静默吞掉；所有随机源和版本可复现。

### 6.7 阶段 6：独立验证

独立验证不得只是再次调用同一个函数。优先顺序：

1. 解析特例或守恒/几何恒等式。
2. 第二种离散、第二个库或独立实现。
3. 小规模穷举/精确求解。
4. 上下界和最优性间隙。
5. 留出数据、滚动外推或情景复现。

通过条件：核心结论至少有一项独立证据；否则状态只能是 provisional。

### 6.8 阶段 7：结果审计、绘图与论文闭环

每个结论绑定同一次运行产生的表、图和摘要数字。图先定义要证明的主张，再选图型；坐标轴、单位、置信区间、事件点、基线和样本量必须可见。

通过条件：摘要数字可追到结果表和脚本；表中数字可由导出方案重算；论文不得手工复制不同运行的数字。

## 7. 按题型配置的专业验证包

### 7.1 机理、PDE、ODE

最低配置：

- 控制体或力学推导，明确初边值条件。
- 量纲和符号方向检查。
- 至少三档步长/网格的收敛表。
- 解析特例、稳态解、守恒量或高精度参考解。
- 参数辨识的置信区间/相关性与留出验证。
- 关键参数联合扰动，而非只动一个参数。

推荐图：机理示意图、拟合与留出曲线、残差图、网格收敛图、参数响应/置信带。

### 7.2 几何、轨迹、碰撞与覆盖

最低配置：

- 坐标系、角度方向、实体边界定义。
- 区分无限直线、有限线段、矩形/多边形、带半径实体。
- 广相筛选的漏检证明或随机全量抽查。
- 连续事件函数 h(t)=0 的括区间和求根残差。
- 退化情形：端点接触、切触、平行、重合、空区间。
- 最终方案用真实实体而非中心点代理再次保守审计。

推荐图：等比例几何图、实体边界和安全裕度、事件函数及阈值、局部放大、连续轨迹动画帧。

### 7.3 单目标/多目标优化

最低配置：

- 决策域、目标、逐条约束和容差。
- 至少一个已知可行基线。
- 最终方案的最大约束违反量和可行率。
- 多初值/多种子、收敛曲线和停止原因。
- 嵌套可行域支配检查。
- 有条件时报告全局界、最优性 gap 或小规模精确对照。

推荐图：收敛曲线、约束裕度、基线对比、目标剖面、多目标 Pareto 前沿和权重稳定性。

### 7.4 调度、离散事件与随机仿真

最低配置：

- 状态机、事件表、资源占用与队列规则。
- 事件前后状态不变量和无冲突检查。
- 小规模手算或精确规划对照。
- 理论上下界及其松紧度说明。
- 随机情景的预热、重复次数、种子、均值、分位数和置信区间。
- 甘特图/时间线与事件日志一致。

推荐图：状态转移图、甘特图、资源利用率、等待时间分布、产出分布、上界差距。

### 7.5 统计分析、预测与决策

最低配置：

- 缺失与异常的机制、数量和处理敏感性。
- H0/H1、统计量、p 值、效应量、区间和诊断。
- 标准化、特征选择和多重共线性检查。
- 严格按时间或组别切分，预处理只在训练集拟合。
- 朴素/季节基线、滚动验证、MAE/RMSE/MAPE 等适配指标和预测区间。
- 预测进入优化时，保留不确定性场景，不能只使用点预测。
- 价格—需求、补货—损耗、服务水平等业务关系必须在目标/约束中闭环。

推荐图：分布与缺失图、相关热图、残差/QQ/ACF、滚动预测、误差分布、情景下决策稳定性。

## 8. 必须实现的硬校验门槛

建议 Agent 对每一道赛题输出 gates.json 或等价表格。每项状态只允许 verified、provisional、failed；任何 failed 关键项阻止生成“最终结论”。

### G0 身份与输入门

- 题面、附件、资料版本与哈希已记录。
- 文件名、首页标题、题号、年份相互一致。
- 无法核验的奖项、作者或来源不作肯定陈述。

### G1 任务覆盖门

- 每个子问、表格、精度和输出文件都有对应产物。
- 摘要、正文、结果附件的问号编号一致。

### G2 单位与语义门

- 量纲检查通过，时间频率唯一且一致。
- 指标定义、公式、表头和自然语言使用同一口径。
- 无限线/线段、插值/校准/预测、拟合/外推、近似/精确等语义不混用。

### G3 数据门

- 缺失、异常、重复、对齐和删样本数量可追踪。
- 训练/验证/测试严格隔离，时间泄漏检查通过。
- 聚类/回归等需要的标准化只由训练数据估计。

### G4 数值收敛门

- 网格、步长、采样射线、蒙特卡洛样本量至少有三档。
- 关键输出和约束裕度随精化趋稳。
- 没有收敛时，结论降级并报告误差范围。

### G5 统计推断门

- H0/H1、p 值判定与自然语言结论一致。
- 报告效应量/系数区间，不以 p<0.05 代替实际意义。
- 残差、共线性、自相关、异方差等诊断按模型类型执行。

### G6 求解器与随机性门

- 求解器状态、容差、迭代数、停止原因、版本已保存。
- 随机种子和多次重复结果已保存。
- 启发式结果没有被标注为全局最优，除非有独立证明或界。

### G7 可行性门

- 从最终导出表重新计算全部约束。
- 报告最大违反量、最小安全裕度和边界约束列表。
- 取整、四舍五入后再次复核可行性。

### G8 跨问支配门

- 若后一问放宽变量/约束，最大化目标不得低于前一问，最小化目标不得高于前一问。
- 上一问方案必须作为下一问初始可行解和回归基线。
- 失败时先判模型口径、代码实现或局部搜索问题，不得直接接受新结果。

### G9 独立验证门

- 至少一个核心结论被第二方法、解析特例、精确小实例或上下界复核。
- 主求解和验证不得共享同一处潜在错误实现。

### G10 鲁棒性与不确定性门

- 关键参数、权重、情景和数据扰动已覆盖。
- 报告结论稳定区间、排名变化或失效边界。
- 随机仿真报告置信区间而非单次样本。

### G11 主张—证据门

- 每条关键主张对应来源、脚本、表/图、验证方法和状态。
- provisional 主张在摘要和结论中显式降级；failed 主张不得进入摘要。

### G12 图表门

- 图有明确主张，轴、单位、图例、样本量和不确定性齐全。
- 几何图等比例；预测图分训练/验证/未来；优化图有基线和约束。
- 正文、图、表数字来自同一次运行。

## 10. Agent 产物契约

每次完整建模至少生成以下逻辑产物；具体文件格式可由宿主系统决定。

1. provenance：题面、附件、资料来源、哈希、版本与证据边界。
2. problem-map：逐问输入、输出、依赖、单位、精度和交付映射。
3. model-cards：每个模型的变量、方程、目标、约束、假设和适用域。
4. baseline-report：最小基线、小规模精确解或解析特例。
5. run-manifest：环境、工具、模型/API、随机种子、参数、入口脚本。
6. solver-log：状态、迭代、容差、失败重试、运行时间。
7. result-tables：未取整原值、论文展示值和单位。
8. validation-report：G0–G12 状态、收敛、可行性、独立复算、鲁棒性。
9. claim-evidence-map：摘要与结论逐条链接到表、图、脚本和验证状态。
10. figures：正式图、绘图脚本和可编辑矢量版本。
11. paper：摘要、模型、求解、验证、评价、参考文献和 AI 使用说明。

## 11. 作图能力应成为模型能力，而非装饰能力

Agent 的作图模块应按“主张类型”路由：

| 主张 | 必备图 | 强制元素 |
|---|---|---|
| 机理/拟合正确 | 实测—模拟对照 + 残差图 | 留出区间、单位、误差指标、置信带 |
| 数值已收敛 | 网格/步长—关键输出图 | 至少三档、相对变化、容差线 |
| 优化有效 | 收敛曲线 + 基线对照 + 约束裕度 | 多种子带、最好/中位、可行边界 |
| 连续事件正确 | h(t) 与阈值局部图 + 实体几何图 | 根区间、残差、等比例、最小间距位置 |
| 调度可靠 | 甘特图/时间线 + 利用率/等待分布 | 事件编号、资源冲突检查、随机区间 |
| 预测有效 | 训练/验证/未来分段图 + 误差分布 | 朴素基线、滚动窗、预测区间 |
| 多目标权衡 | Pareto 前沿 | 可行点、代表解、目标单位、膝点依据 |
| 鲁棒性 | 参数响应/龙卷风/情景箱线图 | 扰动范围、基准、失效阈值 |

所有正式图应做到中文字体可用、色盲友好、灰度可辨、轴与单位完整；几何图必须等比例；静态位图至少 300 dpi，并保留 PDF/SVG 等矢量版本。图中的数值不得手工录入，应直接读取结果表。

## 12. 最重要的实现优先级

如果只能先实现一部分专业能力，优先顺序如下：

1. 约束逐行复算与跨问支配检查。它能直接拦截 A127、A175、C050 级别的致命错误。
2. 主张—证据映射和结论状态控制。没有验证的结果不能进入摘要。
3. 数值收敛、随机重复和独立验证。它们决定机理与优化结果是否可信。
4. 统计时间切分、泄漏检测、假设五联表。它们决定预测类问题是否真正有效。
5. 真实几何实体与连续事件求根。它们决定轨迹、碰撞、覆盖类问题是否语义正确。
6. 事件驱动仿真与小规模精确对照。它们决定调度类近似方案是否有可信边界。
7. 图表主张契约与同源生成。它们把计算证据转化为可审阅论文。

最终标准不是“用了多少模型或工具”，而是：每一问均有清晰的现实语义、可复跑的计算链、独立的验证证据、可审计的约束余量，以及与证据强度一致的结论措辞。
