## 2. 跨年份总规律

### 2.1 高质量路线从不变量开始

跨年份最稳定的起点不是算法名，而是问题中的不变量和生成机制：

- 制动器、软着陆、系泊、波浪能：受力、力矩、能量和状态演化。
- 储油罐、太阳影子、CT、FAST、定日镜：坐标、几何约束、投影或反射关系。
- 土壤污染、葡萄酒质量：指标定义、测量可靠性、空间或变量关联结构。
- 交通、回焊炉、高压油管：守恒关系、连续/离散状态转移和控制输入。

Agent 应先写出实体、状态、控制量、观测量、参数、不变量、边界条件与单位，再选择求解器。没有这一步，不得直接调用遗传算法、粒子群、蒙特卡洛或机器学习。

### 2.2 优秀论文常复用同一个计算内核

典型模型链是“基础模型 → 参数辨识 → 预测/仿真 → 约束优化 → 验证”，而不是每问换一套模型：

- 热传导模型同时承担温度预测、参数反演、厚度或速度优化。
- 动力学方程同时承担状态计算、功率积分和阻尼优化。
- 几何递推同时承担定位、碰撞/可见性判断和布局优化。
- 交通流/状态机同时承担容量估计、排队演化和控制策略比较。

后一问应显式标出复用的变量、函数、参数和可行方案。若后一问放宽可行域，必须注入前一问方案作为基线，并检查目标值的支配关系。

### 2.3 真正有价值的创新通常发生在优化器之前

语料中可迁移的高价值改进包括：利用对称性降维、把连续过程改写成事件过程、按空间邻域减少碰撞/遮挡检查、用分区参数化代替逐对象优化、先解析消元再数值求解、用物理可行域生成器代替随机罚函数。

这类创新直接利用题目结构，往往比更换元启发式算法更可靠。任何降维或筛选都必须给出不漏解证明、保守界或全量抽查。

### 2.4 历史优秀论文可以学习，也必须反证

资料中的论文并非无误。常见薄弱点包括：训练拟合被当成预测验证、只用一个很小步长而不做收敛、随机算法只报最好一次、缺少最优性界、公式与表格口径不一致、放宽可行域后目标反而变差、灵敏度只扰动一个参数、用复杂方法名代替互补证据。

Agent 的目标不是复刻历史论文，而是保留其结构化思路并用更严格的可复现验证升级。

### 年份不是检索条件的唯一入口

新题应按结构而非年份匹配：

- 热、扩散、传质：优先检索 2018、2020。
- 刚体/流体/受力与功率：优先检索 2009、2014、2016、2022。
- 几何反演、成像、反射：优先检索 2010、2015、2017、2021、2023。
- 空间统计与综合评价：优先检索 2011、2012。
- 交通、调度、阀门等混合连续-离散过程：优先检索 2013、2019。

## 4. 简单模型优先的五级阶梯

每个子问题按以下顺序升级。只有当前一级的不足被实际误差、约束冲突或计算瓶颈证明后，才能进入下一级。

### L0：量纲、极限与手算

写出单位、数量级、零输入/满载/稳态/对称等极限情形，构造一个手算结果或理论上下界。这一层用于发现方向、符号和单位错误。

### L1：解析或低维确定性基线

优先用守恒方程、几何关系、线性回归、单因子评价、静力平衡、简化排队或解析特例。基线必须能独立运行和产生结果，不是只写一个模型名。

### L2：确定性数值模型

当解析解不可得时，使用 ODE/PDE 数值解、确定性搜索、线性/整数/非线性规划、事件驱动状态机或精确几何算法。先报告求解器状态、容差和收敛。

### L3：结构化复杂模型

只有在基线误差或约束处理不足时，引入多物理耦合、分区参数化、多目标优化、鲁棒优化或组合算法。复杂度必须来自问题结构，而非为了堆模型。

### L4：随机、启发式或机器学习

只在非凸大规模搜索、真实随机过程或复杂数据关系确实需要时采用。必须保留 L1/L2 基线，固定并记录多个随机种子，报告分布而非最好一次；机器学习必须做结构匹配的样本外验证与解释。

## 5. 算法创新的准入与验收

允许并鼓励创新算法，但创新必须解决一个已经证实的瓶颈。

### 5.1 合格创新的来源

- 利用对称性、守恒量、单调性、凸性、稀疏性、邻域或可分结构降维。
- 把连续时间逐步仿真改为事件驱动，把全量碰撞/遮挡改为有证明的广相筛选 + 精确窄相。
- 解析消元后只优化剩余自由度，或先构造可行解再局部精化。
- 将确定性全局粗筛与局部高精度求解结合。
- 将随机算法限制在候选生成，并由确定性可行性审计器和独立复算验证最终方案。
- 为特定问题设计自适应步长、约束修复、分层编码或领域启发式。

### 5.2 创新算法必须回答的问题

1. 经典基线在哪个指标上不足：精度、速度、内存、可行率、鲁棒性还是约束表达？
2. 新算法利用了什么题目结构，为什么预期有效？
3. 去掉每个新增模块后性能如何，即消融实验结果是什么？
4. 复杂度、收敛性或停止条件是什么？若无法证明收敛，经验稳定区间是什么？
5. 在相同数据、预算、容差和硬件下，与简单基线相比提升多少？
6. 对初值、种子、参数和数据扰动是否稳定？
7. 在什么条件下应回退到经典算法？

### 5.3 创新算法验收表

| 维度 | 最低证据 |
|---|---|
| 正确性 | 小规模精确解、解析特例或独立实现至少一种 |
| 可行性 | 从导出方案逐条重算全部硬约束和最大违反量 |
| 增益 | 与最简单合格基线在同预算下比较，不只与弱基线比较 |
| 消融 | 每个创新模块至少有一次关闭/替换实验 |
| 稳定性 | 多初值或至少 5 个有效随机种子；报告中位数、四分位和失败率 |
| 代价 | 时间、内存、函数评估次数和复杂度说明 |
| 边界 | 适用条件、失效情形和回退路线 |

只换算法名称、叠加多个元启发式、增加随机数或只展示单次最好值，不构成创新。

## 6. 从历史论文缺陷反推的硬门禁

### G-A1：基线门

主模型前必须有一个可执行的 L0/L1 基线。复杂模型若未显著改善任务指标或约束质量，应优先保留简单模型。

### G-A2：量纲与守恒门

机理问题必须检查单位、初边值、力/力矩/质量/能量残差和极限情形。数值曲线形状合理不能替代这些检查。

### G-A3：离散收敛门

ODE/PDE、射线采样、时间仿真和数值积分至少使用三档步长/网格/样本量，报告关键输出与约束裕度的变化。只声明“步长很小”不通过。

### G-A4：随机重复门

GA、PSO、SA、蒙特卡洛和随机仿真至少使用 5 个有效独立种子；正式结论报告分布、成功率和停止状态，摘要不得只写最好一次。

### G-A5：拟合与预测分离门

参数辨识、回归和机器学习必须区分样本内拟合、插值与未来/新主体预测。预测主张必须有时间或主体结构正确的样本外验证。

### G-A6：可行域支配门

后一问放宽变量或约束时，最大化目标不得低于前一问已知可行方案，最小化不得高于；旧方案必须注入新模型作为回归测试。

### G-A7：公式-代码-表格一致门

指标定义、目标方向、单位、表头和摘要必须同口径。最终表从原始导出变量重新计算，不手工抄写中间值。

### G-A8：创新证据门

创新算法未通过同预算基线、消融、复杂度、稳定性和失效边界检查时，只能称“候选改进”，不能称“有效创新”或“优于经典算法”。

### G-A9：结论强度门

启发式结果没有全局界、精确小实例或充分最优性条件时，只能写“当前找到的最好可行解”“近似解”或“候选方案”，不得写“全局最优”。

## 7. 检索与使用流程

1. 先把新题拆成“现实机制 + 数学对象 + 计算瓶颈”，不要先搜算法名。
2. 在 [a-paper-corpus-index.md](a-paper-corpus-index.md) 中按年份/题型确定候选论文；需要更精确页码时读取 [a-paper-corpus-index.json](a-paper-corpus-index.json) 中的 `methodPages` 与 `validationPages`。
3. 用 `search_materials` 组合检索“场景词 + 结构词”，例如：
   - `热传导 参数辨识 网格收敛`
   - `太阳影子 非线性最小二乘 可辨识性`
   - `系泊 受力平衡 多目标`
   - `FAST 抛物面 促动器`
   - `定日镜 遮挡 分区布局`
4. 用 `read_material` 读取命中页；涉及公式、表格、图和 OCR 页时必须打开原 PDF 核验。
5. 从候选论文提取三类信息：可迁移结构、历史实现、历史缺陷。不得只提取模型名称。
6. 为新题建立 L0-L4 路线，默认停在能满足指标的最低层级。
7. 若提出创新算法，执行第 5 节验收表；若使用随机或机器学习路线，同时执行 G-A4/G-A5。
8. 将原论文只作为来源证据。新题的数值结果、可行性、收敛和鲁棒性必须由本次计算产生。

最终选择原则：简单、可解释、可验证的模型优先；有明确瓶颈和实证增益时积极创新；随机数和机器学习永远不能代替问题结构分析。
