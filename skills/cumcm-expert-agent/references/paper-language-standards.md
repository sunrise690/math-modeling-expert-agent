# 国赛论文语言与术语规范

## 1. 先建立术语表

在撰写正文前，为同一数学对象固定一个名称，并在全文保持一致。正文使用“问题一、问题二……”；`Q1`、`Q2` 只用于代码、文件名或紧凑图内标记。

几何遮蔽类论文优先使用下列术语：

| 含义 | 统一表述 | 避免表述 |
|---|---|---|
| 以目标中心为代表的判据 | 中心视线判据；首次可注明“基准判据” | 主口径、评分口径 |
| 要求目标实体整体被遮蔽 | 圆柱整体遮蔽判据；首次可注明“保守判据” | 完整圆柱审计、二次审计 |
| 连续时间端点计算 | 连续求根、连续精化 | 连续验根、连续复算 |
| 独立实现再次计算 | 独立复核 | 独立复算、二次审计 |
| 由离散网格定位根 | 离散扫描确定根区间 | 括区器、事件发现器 |
| 同一航路上的若干动作 | 同航路组合、候选组合 | 候选包、路线包、投放包 |
| 从结果表重建并检查 | 结果表反算、一致性检验 | 工作簿回读、审计回读 |
| 随机搜索的重复运行 | 多随机初值试验、多随机种子试验 | 多种子审计、种子离散 |
| 启发式算法输出 | 当前搜索得到的可行解 | 终稿策略、入选状态 |

## 2. 删除开发过程语言

论文正文只保留模型、求解、结果和验证。以下内容属于程序日志、Agent 内部质检或项目管理，不得直接进入竞赛论文：

- `run_id`、JSON、工作簿回读、搜索记账、聊天记录、论文产物；
- “算法披露”“证据链”“质量标定”“向后接口”“图件主张”；
- “不直接信任优化器”“不编造分布”“不再使用某种图”等对抗式说明；
- 候选数量、缓存数量和保留宽度的逐项日志，除非它们决定算法复杂度或结果边界。

把内部过程改写为正向、可检验的学术陈述。例如：

- 不写“终稿策略一律连续复算”，写“最终候选采用连续求根计算有效区间”。
- 不写“工作簿回读证明可执行”，写“根据结果表重新计算全部约束，最大违反量为 0”。
- 不写“不宣称全局最优”，写“由于尚无全局界，结果按可行解报告”。

## 3. 使用自然的小节结构

根据每问的数学内容选择标题，不机械复制同一套模板。常用标题包括：

- 模型建立、连续优化模型、区间协同模型、联合指派模型；
- 求解方法、参数设置、求解结果、机理分析、结果检验；
- 模型优点、模型局限、敏感性分析、可行性检验。

每问仍需形成“任务—模型—求解—结果—解释—检验”闭环，但这些要素可以合并到自然段或因题而异的小节中。

## 4. 结果句必须回答“多少、为何、能说明什么”

结果分析至少包含以下两层：

1. 报告指标、数值、单位、约束条件和比较对象。
2. 用几何、物理、统计或优化机制解释结果结构。

避免只写“图中可以看出结果较好”。优先写成：“三枚烟幕弹的单独时长之和为 6.814 s，并集为 6.631 s，0.183 s 的差值来自相邻烟幕的重复覆盖；该重叠换取了连续遮蔽区间的衔接。”

因果解释的证据不足时，使用“与……一致”“可能与……有关”，不要直接写“原因是”。统计学中的“显著”只用于有明确显著性检验的场合；单纯幅度较大时写出具体百分比。

## 5. 控制否定式和元话语

“不能、不构成、不宣称、不是、不把”等边界说明集中放在结果检验或模型局限中。摘要只保留影响结论理解的关键限制，各问正文不反复解释同一边界。

避免强行组织“第一、第二、第三”的三段式贡献，也避免“本文不是……而是……”等答辩腔。直接陈述采用了什么模型、为何适用、得到什么结果。

## 6. 图题和表题

图题采用“研究对象 + 比较条件 + 主要图层”的结构，正文另用 1--3 句解释图中结论。图题不写：

- 具体颜色名称，如“陶土色点”“蓝线”；
- 制图过程，如“未裁切”“不用插值”“真实数据”；
- 质检术语，如“三层证据”“唯一主张”“阅读边界”；
- 与图中没有对应面板的 A/B/C 说明。

表题说明表中对象和条件；表头直接给出变量或指标及单位。结果表不把“审计”作为指标名，改用“复核”“一致性检验”或“相对下降率”。

## 7. 摘要和关键词

摘要最后撰写，按问题顺序给出任务、方法、量化结果和必要边界。每问至少包含一个真正回答题目的数值，随机种子数、迭代次数不能代替结果。

国赛关键词行使用 `\textbf{关键词：}` 或等价的加粗标签；关键词本身保持 4--6 个，选用问题对象、核心模型和关键算法，不使用“审计”“证据链”等内部术语。

## 8. 终稿语言检查

发布前逐项确认：

- [ ] 同一对象全文只使用一个核心名称。
- [ ] 正文中的 `Q1`--`Q5` 已改为“问题一”--“问题五”。
- [ ] 无 `run_id`、JSON、聊天记录、工作簿回读、搜索记账等开发痕迹。
- [ ] 无“算法披露、质量标定、主口径、完整圆柱审计、候选包”等高风险措辞。
- [ ] 每个结果段既有数值，也有与证据强度匹配的机理解释。
- [ ] “显著、稳定、可靠、最优”均有对应统计量、重复试验或理论依据。
- [ ] 图题不依赖颜色名称，不含制图过程说明。
- [ ] 关键词标签已加粗，摘要数字与正文、表格和结果文件一致。
