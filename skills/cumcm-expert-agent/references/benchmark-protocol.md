# 历史赛题盲测与 Agent 迭代

## 目的

用完整历史赛题检验 Agent 是否能独立完成工程，而不是复述现成答案。基准输入只包含官方题面、附件、允许的通用资料和明确的工具能力。

## 运行

1. 建立全新项目目录，记录题面与附件哈希。
2. 不向执行 Agent 提供参考答案、旧结果或预期最优值。
3. 固定 Provider、模型、推理档位、随机种子和工具版本。
4. 执行拆题、路线选择、计算、绘图、验证、填表和论文交付。
5. 保存工具事件、运行时长、失败重试和人工介入点。

## 评分维度

- 逐问覆盖和模板完整性。
- 题意、单位、几何/物理约束正确性。
- 代码可复现、求解器状态和结果一致性。
- 独立校验、灵敏度与鲁棒性。
- 图表是否真正支撑主张。
- 摘要数字与计算证据闭环。
- 隐私、引用、AI 使用和仓库边界。

## 更新规则

把失败归因到 `skill`、工具、资料索引、Provider 适配、质量评分或任务实现之一。只修改能泛化的规则或能力，不把某年某题的答案写进 skill。更新后清空旧运行产物，用同一官方输入重跑；同时用另一道结构不同的题做回归，防止过拟合。
