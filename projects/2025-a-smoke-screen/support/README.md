# Support Materials

Project: 2025 A 烟幕干扰弹的投放策略

This directory stores process and audit materials that should not be mixed into the paper body.

- `data_processing.md`: data cleaning and field handling.
- `model_running.md`: commands and environment notes.
- `verification_report.md`: per-subquestion verification status.
- `quality_gate_report.md`: latest quality-gate result and fixes.
- `self_check_report.md`: contest-paper self-check.
- `ai_usage.md`: AI/LLM use record if applicable.
- `run_log.md`: reproducibility run log.
